# Kế hoạch: auto-disable defaults + metering + tối ưu prompt (codex-rs)

## Context

Đã trace bằng codegraph toàn luồng: `run_turn` → `build_initial_context_with_world_state_and_mcp` (session/mod.rs:3202) → `build_prompt` (turn.rs:1122) → `build_responses_request` (client.rs:881). Init token lớn vì: base prompt theo model (6.6–24KB), skills/plugins/permissions/personality fragments, AGENTS.md mọi cấp, tool schemas full bộ. Nhiều fragment đã có điều kiện render sẵn — chỉ cần đổi default/gate chặt hơn. Kế hoạch gồm 4 PR nhỏ, mỗi PR độc lập.

## PR-1: Auto-disable defaults cho fragments (nhanh, rủi ro thấp)

- **Skills**: khi `build_available_skills` trả rỗng → không render khung hướng dẫn (hiện có thể vẫn render body hướng dẫn) — `core/src/session/mod.rs:3335` + `available_skills_instructions.rs`.
- **Recommended plugins + thread_hint**: gate chặt khi không auth/không plugin (`tool_suggest_enabled` + MCP call `thread_hint` mod.rs:3388 chỉ chạy khi thật sự dùng).
- **Permissions instructions**: rút gọn khi approval=never hoặc sandbox full-auto (`PermissionsInstructions::render` — thêm variant ngắn).
- **Personality/realtime**: verify không render khi không bật (nếu render rỗng thì sửa).
- **Reminders**: `maybe_record_reminder`/`maybe_record_current_time_reminder` (turn.rs:242,256) đổi thành cache per-day + config `[context] time_reminders = off` — tránh phá prompt cache prefix mỗi turn.
- Config mới trong `codex-config`: `[context] skills = auto|on|off`, `[context] plugins = auto|on|off` (default `auto` = chỉ render khi có nội dung).

## PR-2: Metering token per-request (nền đo)

- Migration `state/migrations/00xx_turn_usage.sql`: bảng `turn_usage(thread_id, turn_id, model, input_tokens, cached_tokens, output_tokens, created_at)`.
- Ghi tại `record_token_usage_info` (turn.rs:2383) — lấy token_usage từ SSE (đã có `TokenUsageInfo` trong history.rs).
- Lệnh `codex usage` (CLI) đọc bảng, in tổng/tuần/provider. TUI footer hiển thị tokens turn hiện tại (đã có `send_token_count_event`).

## PR-3: Tool pack theo mode (cắt lớn nhất mỗi request)

- `ToolRouter.model_visible_specs()` (`core/src/session/turn.rs` built_tools): lọc specs theo `turn_context.collaboration_mode.mode` — Plan chỉ read-only, loại apply_patch/exec nặng khỏi Research/review; giữ MCP tools do user cấu hình.
- Đảm bảo khi mode đổi giữa turn → tool specs đổi + developer message thông báo (đã có `build_collaboration_mode_update_item` updates.rs:64).
- Snapshot test TUI + integration test `core/suite` assert tool list theo mode.

## PR-4: Base instructions nhẹ + AGENTS.md cap

- Cho phép override base prompt: config `[model] base_instructions_file = path` (đọc 1 lần ở ConfigBuilder, thay `get_model_instructions` — `model_info.get_model_instructions`).
- AGENTS.md: cap tổng ký tự (tận dụng truncation helpers của `internal_model_context`) + warning khi vượt; chỉ nạp AGENTS.md của cwd và root (bỏ cấp giữa) — config `[context] agents_md_depth`.
