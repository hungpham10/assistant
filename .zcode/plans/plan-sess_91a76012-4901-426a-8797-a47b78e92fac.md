# PR-3: `/tools` — bật/tắt tool trong phiên chat (TUI) + tầng chọn tool trong core

## Context

Tất cả nguồn tool (builtin, MCP, extension, dynamic) hội tụ tại `build_model_visible_specs_and_registry` (core/src/tools/spec_plan.rs:236) và luôn được advertise đầy đủ cho model — không có cách bật/tắt tool trong lúc chat. Mục tiêu: lệnh `/tools` trong console chat cho phép xem danh sách tool và bật/tắt **theo phiên**, áp dụng ngay từ câu kế tiếp. Nguyên tắc: tool bị tắt chỉ **demote `Direct → Deferred`** (không xoá) — model không thấy schema ban đầu nhưng `tool_search` vẫn tìm được, không mất chức năng.

## Phần A — Core

1. **`core/src/tools/selection.rs` (mới)**:
   - `SessionToolSelection { deny: HashSet<ToolKey>, enable: HashSet<ToolKey> }`; `ToolKey` = tên tool hoặc `namespace:*` (MCP).
   - `apply_tool_selection(turn_context, session_selection, planned) -> PlannedTools` — thứ tự: protected tools (`PlanHandler`, `RequestUserInputHandler`) giữ nguyên → Plan mode demote builtin write tools (shell/unified_exec, apply_patch, alias Write/Edit/Bash) → session/config deny (trừ khi trong session enable) → còn lại giữ nguyên.
2. **State phiên**: field `tool_selection` trong `SessionState` (core/src/session/mod.rs) + `Op::SetToolEnabled { name, enabled }` (protocol/src/protocol.rs:531) → handler cập nhật + emit developer message ngắn informing model.
3. **1 callsite**: `build_model_visible_specs_and_registry` gọi `apply_tool_selection` sau `add_tool_sources`. Router dựng lại mỗi sampling request (turn.rs:1166) → hiệu lực ngay câu kế tiếp. Default mode không toggle gì = hành vi hiện tại (tương thích ngược).

## Phần B — TUI `/tools`

- `SlashCommand::Tools` (tui/src/slash_command.rs) — "enable/disable tools for this session".
- Dispatch trong `slash_dispatch.rs` (mẫu `/mcp` :484/:686): `/tools` mở picker; `/tools on|off <name>`; `/tools reset`.
- Picker tái dùng `SelectionViewParams` (bottom_pane, như /keymap): mỗi dòng `[on]/[off] name (nguồn)`; builtin catalog tĩnh + MCP tools từ nguồn `add_mcp_output`. Chọn dòng → `Op::SetToolEnabled` → render lại.
- Snapshot test TUI bắt buộc (insta) cho picker + info message.
